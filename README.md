# Ahmad Hassan — Portfolio

React + Vite + Tailwind CSS v4 + Framer Motion + Lenis.

## Run
npm install
npm run dev        # http://localhost:5173

## Edit content
Everything (text, links, skills, projects, CV file) is in `src/data.js`.
CV PDF: `public/Ahmad_Hassan_CV.pdf` · Photo: `src/assets/ahmad.webp`

## Deploy (Vercel)
Push to GitHub → import the repo on vercel.com → Framework: Vite → Deploy.
